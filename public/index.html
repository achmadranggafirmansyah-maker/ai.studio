⚙️ Cara Pakai Motion Control

1. Buka colab.research.google.com di tab lain
2. Upload file colab.ipynb (ada di folder project)
3. Set GPU: Runtime → Change type → T4 GPU
4. Run semua cell, tunggu sampai muncul URL trycloudflare.com
5. Copy URL itu, paste di kolom di bawah
6. Baru bisa generate motion control
